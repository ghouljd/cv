# Jesus David Escalante Rodriguez — CV

Bilingual resume in English and Spanish, published on GitHub Pages.

**Website:** https://ghouljd.github.io/cv/

## Features

- English by default, with an English / Español selector.
- Responsive layout for desktop and mobile.
- Print or save as PDF in the selected language, formatted for two A4 pages.
- Standalone HTML, CSS, and JavaScript; no build tools or external dependencies.

## Local preview

Open `index.html` in a browser, or serve this directory with a static HTTP server.

## Update the CV

Edit `index.html` and push changes to `main`. GitHub Pages publishes from the repository root on that branch.

Translated text uses `data-en` and `data-es` attributes. Keep both versions in sync when updating content.
